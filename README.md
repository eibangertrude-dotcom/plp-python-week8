# Personal Mini-Toolkit

## PLP Week 8 Final Python Project

### Project Description

The Personal Mini-Toolkit is a menu-driven Python application that combines different beginner-level programming concepts into one program.

It provides three useful tools:

1. **To-Do List Manager** – Allows users to add, view and remove tasks.
2. **Even or Odd Checker** – Determines whether an entered number is even or odd.
3. **Multiplication Table Generator** – Generates a multiplication table from 1 to 10 for any whole number.

### Python Concepts Used

- Variables and data types
- User input and output
- If, elif and else statements
- For loops and while loops
- Lists and list methods
- Functions
- F-strings
- Exception handling (try and except)

### Project Files

- `toolkit.py` – Main Python application.
- `toolkit_plan.txt` – Project planning document.
- `screenshots/` – Screenshots showing the menu and each tool in action.

### How to Run the Program

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

```bash
python toolkit.py
```

6. Follow the menu instructions to use the tools.

### Testing

The program was tested to confirm that:

- Users can add, view and remove tasks.
- The Even or Odd Checker identifies numbers correctly.
- The Multiplication Table Generator displays results from 1 to 10.
- Invalid menu choices and invalid number inputs are handled gracefully.
- The program continues running until the user selects Quit.

### Personal Reflection

The most challenging part of this project was connecting all three tools to one main menu while ensuring the menu continued running correctly. The bug that took the longest to fix was an indentation and function-placement error involving the if and elif statements. I learned that Python indentation is very important when organizing functions and conditional statements. I also improved my understanding of lists, loops, functions and user input. Testing each tool helped me identify and correct mistakes before completing the project. If I had one more week, I would add more tools such as a calculator and a number-guessing game.
